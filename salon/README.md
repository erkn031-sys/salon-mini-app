# Telegram Mini App для салона красоты — демо для портфолио

Витрина услуг, карточки мастеров, запись в четыре шага и раздел «Мои записи».
Чистый HTML/CSS/JS, без сборки и зависимостей — залить файлы на любой HTTPS-хостинг и указать адрес боту.

## Файлы

| Файл | Что внутри |
| --- | --- |
| `index.html` | разметка всех экранов, подключение Telegram SDK и шрифтов |
| `styles.css` | дизайн-токены, тёмная и «мокко»-светлая темы, все компоненты |
| `app.js` | настройки салона, прайс, мастера, логика записи и интеграция с Telegram |
| `img/` | демонстрационные изображения (обложка, мастера, примеры работ) |

## Как настроить под салон

1. В `app.js` сверху — блок `SALON`: название, город, адрес, часы, телефон, почта, ссылка на чат администратора, часы работы для сетки слотов.
2. Ниже — массивы `SERVICES` (услуга: категория, название, описание, цена, минуты), `MASTERS` (имя, роль, описание, фото, категории услуг) и `REVIEWS`.
3. Фото мастеров и примеров работ заменить файлами в `img/` с теми же именами.
4. Категории задаются объектом `CAT` — при добавлении новой не забыть кнопку-фильтр в `index.html`.

## Как подключить к боту

1. Залить папку на HTTPS-хостинг (GitHub Pages, Vercel, Netlify, свой сервер).
2. @BotFather → `/newapp` → выбрать бота → загрузить иконку → указать URL приложения. Запуск: `https://t.me/<бот>?startapp`.
3. Или `/setmenubutton` — кнопка мини-аппа в меню чата.
4. Заявка уходит боту через `WebApp.sendData` (обработчик `web_app_data`). Это работает только при запуске из кнопки обычной клавиатуры (`KeyboardButton` с полем `web_app`). Для inline-кнопок и главного меню отправляйте бронь запросом на свой backend и проверяйте подпись `initData`.

## Что уже сделано по платформе

- `MainButton` и `BackButton` Telegram вместо кнопок внутри страницы, прогресс при отправке.
- Хаптика: выбор услуги, даты, слота и успешное подтверждение.
- Тема клиента (`themeParams`, `colorScheme`) с реакцией на смену темы; безопасные зоны и `viewport-stable-height`.
- `CloudStorage` для истории визитов, повтор и отмена записи.
- Вне Telegram включается портфолио-демо: плашка-пояснение и эмуляция нижней кнопки.

Данные в демо вымышленные: «Мастер 1–3», «Гость 1–4», адрес и телефон-заглушки.
